# 协作工作区

浏览器用户进入的是同一个实时工作区，适合远程演示、结对排障、教学和临时运维协作。

## 可共享的内容

在工作区中，你可以：

1. 创建终端窗口，并拖动、缩放、聚焦或关闭它们；
2. 与其他用户实时查看同一终端的输出；
3. 创建共享 Markdown 窗口，记录命令、步骤和排障笔记；
4. 使用画布组织说明和讨论内容；
5. 通过参与者列表与多人光标查看当前协作状态。

终端的输出会保留在工作区中，并同步给稍后加入的浏览器用户。一个由 Web 工作区创建的 Shell 是共享资源，请在执行具有破坏性的命令前与协作者确认。

## 平铺布局也是共享的

除了窗口的位置与尺寸，**平铺（tiled）模式下的窗格布局也是房间内共享的**：哪个窗口属于哪个窗格、分割方向与比例、以及被拖出网格的自由窗格，都会同步给所有协作用户。任一成员调整分割、交换窗格或将窗格拖出为自由层，其余用户会实时看到相同的平铺布局。

- **自由 / 平铺 切换是本地偏好**：每个用户可在自己的浏览器中选择用自由画布（自由）或平铺窗格（平铺）查看同一份共享内容，该偏好会保存并在刷新后恢复；
- 共享的平铺布局通过工作区 WebSocket 由服务端维护并持久化；Yjs `/collab` 仅用于 Markdown、画布等协作文档（见 [`persistence`](./persistence.md)）。

## SSH 与 Web 的边界

| 入口 | Shell 行为 | 适用场景 |
| --- | --- | --- |
| SSH | 每次登录创建独立 PTY | 个人命令行工作、脚本和传统远程管理 |
| 浏览器 | 所有 Web 用户共享窗口 | 演示、协作排障、教学和共同记录 |

两个入口都通过同一个监听端口访问，因此无需额外配置端口或部署独立 Web 服务。
