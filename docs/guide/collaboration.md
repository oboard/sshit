# 协作工作区

浏览器用户进入的是同一个实时工作区，适合远程演示、结对排障、教学和临时运维协作。

## 可共享的内容

在工作区中，你可以：

1. 创建终端窗口，并拖动、缩放、聚焦或关闭它们；
2. 与其他用户实时查看同一终端的输出；
3. 创建共享 Markdown 窗口，记录命令、步骤和排障笔记；
4. 使用画布组织说明和讨论内容；
5. 通过参与者列表与多人光标查看当前协作状态。

终端的输出会保留在工作区中，并同步给稍后加入的浏览器用户。一个由 Web 工作区创建的 Shell 是共享资源，请在执行具有破坏性的命令前与协作者确认。

## SSH 与 Web 的边界

| 入口 | Shell 行为 | 适用场景 |
| --- | --- | --- |
| SSH | 每次登录创建独立 PTY | 个人命令行工作、脚本和传统远程管理 |
| 浏览器 | 所有 Web 用户共享窗口 | 演示、协作排障、教学和共同记录 |

两个入口都通过同一个监听端口访问，因此无需额外配置端口或部署独立 Web 服务。
