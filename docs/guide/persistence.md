# 会话持久化

默认情况下，`sshit` 会保存 Web 工作区，并在服务或机器重启后恢复。状态目录为：

```text
~/.sshit/<port>/
```

例如默认端口使用 `~/.sshit/2222/`。

## 会保存什么

- **窗口布局**：终端和编辑器窗口的位置、尺寸及层级；
- **平铺布局**：平铺模式下的窗格划分，随窗口布局一起保存在服务端会话快照中；
- **终端历史**：每个终端窗格之前显示的内容；
- **协作文档**：Markdown 内容和画布数据；
- **AI Agent 会话**：支持的 `claude` 与 `codex` 会话会使用恢复命令重新拉起。
- **自由/平铺偏好**（仅本地）：每个用户当前选择的查看模式保存在其浏览器的 `localStorage` 中，刷新页面后自动恢复。

普通 Shell 进程本身不会跨重启保留。恢复时，`sshit` 会在保存的工作目录启动新的 Shell，再回放已保存的屏幕历史。

## 文件布局

```text
~/.sshit/<port>/
├── session.json       # 窗口与平铺布局、会话元数据
├── collab.json        # 共享 Markdown 与画布状态
└── history/
    └── <id>.txt       # 各终端的滚动历史
```

## 配置行为

```bash
# 默认：保存布局、协作文档和终端历史
sshit

# 不再写入新的终端历史；已有的历史文件仍会在恢复时回放
sshit --persist-history=false

# 完全停用工作区持久化
sshit --persist=false
```

## 敏感信息

终端滚动历史可能包含密码、令牌或敏感命令输出。`sshit` 会以 `0700`/`0600` 权限保存状态目录和文件，但仍应将 `~/.sshit/` 视作 Shell 历史来保护。在共享机器上，建议使用 `--persist-history=false`，或完全停用持久化。
